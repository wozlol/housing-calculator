# Las Vegas Housing and Meals Pilot Budget Calculator

A planning calculator for a pilot that pairs housing with regular meals and ongoing support for unsheltered adults. Built for a local nonprofit, city or county program team, and funding partners. Open `index.html` in a browser. No login, no server, no resident data.

| File | Role |
| --- | --- |
| `index.html`, `style.css`, `app.js` | The page |
| `calc.js` | All calculation code, runs in the browser and in Node |
| `checks.js` | Required math checks. Run `node checks.js`, or open the Math checks tab |

The demonstration values are invented test numbers, not prices. The spec for the math is in `Las_Vegas_Project_Context_and_Calculator_Instructions.txt`.

Hosting: GitHub Pages, branch root.
